# YggdraFlow Frontend

Frontend inicial do YggdraFlow SaaS usando React, TypeScript, Vite, Tailwind CSS, React Router e Axios. Preparado para instalar dependências pelo Git Bash.

Este pacote não inclui `node_modules`.

## Como rodar

```bash
cp .env.example .env
npm install
npm run dev
```

URL padrão do Vite:

```txt
http://localhost:5173
```

## Backend esperado

```txt
http://localhost:3333
```

## Estrutura

```txt
src/
  assets/
  components/
  layouts/
  pages/
  routes/
  services/
  types/
  App.tsx
  main.tsx
  index.css
```
